## User Roles

The manuscript names System Administrator, ETS Personnel, Program Leader, Project Leader, Faculty Extensionist, and University Administration. The existing application stores admin, faculty, and viewer account roles plus leadership/member assignments.

- System Administrator manages accounts, access, settings, and audit records.
- ETS Personnel manage operational records and proposal review.
- Program and Project Leaders work on assigned records and submit proposals/documents.
- Faculty Extensionists contribute supporting documents and accomplishments within their assignments.
- University Administration views dashboards, project status, and institutional reports.

The exact review authority and account-role mapping need confirmation before expanding permissions. The sketch's handwritten user-account question is not treated as authorization to remove accounts, login, or access control.
